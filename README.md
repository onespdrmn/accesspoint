These are some scripts for creating my own access point.

I had two USB dongles (one 2.4 Ghz and one 5 Ghz) that I put in an AWOW single board computer running Ubuntu Linux.

networking.sh is a script that was called from /etc/rc.local to start up the software.

There is no web gui for this access point.  It was administered via ssh.

I bought the USB wifi dongles off of amazon and had good luck with the rtl8821ce and rtl88x2bu
